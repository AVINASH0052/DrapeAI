# Sugatai landing page

Vite + React + TypeScript marketing site for `sugatai.com`.

## Local development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run build
npm run lint
```

The design adapts the 21st.dev fashion hero and iPhone mockup patterns to
Sugatai's brand system. The generated recommendation lives at
`../design-system/sugatai/MASTER.md`.

The early-access CTA currently opens an email to `hello@sugatai.com`. Replace
it with a real waitlist provider before running paid acquisition.
